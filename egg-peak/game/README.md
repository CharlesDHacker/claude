# Egg Peak (Roblox, Rojo)

Design notes live one folder up in the vault. See [Climbing Feel](../Climbing-Feel.md).

1. `rokit install`
2. `rojo serve`, then connect from Roblox Studio.

- `src/shared/ClimbConfig.luau`: every tunable for the climb feel
- `src/client/Climb/ClimbAnimator.luau`: runtime layer on top of your climb animation
